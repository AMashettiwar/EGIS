# Stage handoff index

The handoffs are a development record, not an independent release certificate. `PASS` means the narrow synthetic/public path met its local criteria. `BLOCKED` and `PENDING_EXTERNAL` identify evidence that cannot be manufactured inside the candidate repository.

- [Stage 0](../handoffs/stage-0-handoff.md): contract and answerability
- [Stage 1](../handoffs/stage-1-handoff.md): source acquisition and completeness
- [Stage 2](../handoffs/stage-2-handoff.md): typed normalization and identity
- [Stage 3](../handoffs/stage-3-handoff.md): deterministic inference and abstention
- [Stage 4](../handoffs/stage-4-handoff.md): replay and tamper rejection
- [Stage 5](../handoffs/stage-5-handoff.md): interface fidelity
- [Stage 6](../handoffs/stage-6-handoff.md): held-out acceptance
